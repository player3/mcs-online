# 环境配置说明

## 开发环境要求

### 必需软件

1. **Node.js**
   - 版本要求：14.19+ / 16.x / 18.x
   - 下载地址：https://nodejs.org/
   - 验证安装：`node --version`

2. **npm 或 yarn**
   - npm版本：>= 6.13.4（随Node.js一起安装）
   - 或 yarn版本：>= 1.21.1
   - 验证安装：`npm --version` 或 `yarn --version`

### 可选软件

1. **Git**
   - 用于版本控制
   - 下载地址：https://git-scm.com/

2. **VS Code**
   - 推荐的代码编辑器
   - 下载地址：https://code.visualstudio.com/

### VS Code 推荐插件

- **Volar** - Vue 3 官方支持
- **ESLint** - 代码质量检查
- **Prettier** - 代码格式化
- **EditorConfig** - 统一编辑器配置

## 项目初始化步骤

### 1. 克隆或下载项目

```bash
# 如果使用Git
git clone <repository-url>
cd mcs-online

# 或直接将项目解压到目录
```

### 2. 安装前端依赖

```bash
npm install
```

如果遇到网络问题，可以使用国内镜像：

```bash
# 使用淘宝镜像
npm install --registry=https://registry.npmmirror.com

# 或永久设置
npm config set registry https://registry.npmmirror.com
```

### 3. 安装Mock服务器依赖（用于开发测试）

```bash
npm install express cors body-parser
```

### 4. 启动开发环境

#### 方式一：同时启动前端和后端（推荐）

**Windows (PowerShell):**
```powershell
# 在一个终端启动Mock服务器
Start-Process powershell -ArgumentList "node mock-server.js"

# 启动前端开发服务器
npm run dev
```

**Windows (CMD):**
```cmd
# 在一个终端启动Mock服务器
start cmd /k node mock-server.js

# 在当前终端启动前端
npm run dev
```

**Linux/macOS:**
```bash
# 在后台启动Mock服务器
node mock-server.js &

# 启动前端开发服务器
npm run dev
```

#### 方式二：分别启动

**终端1 - 启动Mock服务器:**
```bash
node mock-server.js
```

**终端2 - 启动前端:**
```bash
npm run dev
```

## API配置

### 开发环境

默认配置：`http://localhost:3000/api`

修改配置文件：`src/boot/axios.js`

```javascript
const api = axios.create({ 
  baseURL: process.env.VITE_API_BASE_URL || 'http://localhost:3000/api'
})
```

### 生产环境

在构建前修改 API 地址为实际的生产环境地址。

## 端口配置

### 前端端口（默认9000）

编辑 `quasar.config.js`:

```javascript
devServer: {
  open: true,
  port: 9000  // 修改为你需要的端口
}
```

### 后端端口（默认3000）

编辑 `mock-server.js`:

```javascript
const PORT = 3000  // 修改为你需要的端口
```

## 常见问题解决

### 1. 端口被占用

**错误信息：** `Error: listen EADDRINUSE: address already in use`

**解决方法：**
- 修改端口号
- 或关闭占用端口的程序

**Windows查找并关闭进程：**
```powershell
# 查找占用端口的进程
netstat -ano | findstr :9000

# 关闭进程（替换PID为实际的进程ID）
taskkill /PID <PID> /F
```

**Linux/macOS:**
```bash
# 查找占用端口的进程
lsof -i :9000

# 关闭进程
kill -9 <PID>
```

### 2. 依赖安装失败

**解决方法：**
```bash
# 1. 清除npm缓存
npm cache clean --force

# 2. 删除node_modules和package-lock.json
rm -rf node_modules package-lock.json

# 3. 重新安装
npm install
```

### 3. 模块找不到错误

**错误信息：** `Cannot find module 'xxx'`

**解决方法：**
```bash
# 重新安装特定模块
npm install <module-name>

# 或重新安装所有依赖
npm install
```

### 4. 跨域问题（CORS）

如果连接真实后端时出现跨域问题，有两个解决方案：

**方案一：后端配置CORS（推荐）**

后端需要添加CORS头：
```javascript
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, PUT, DELETE
Access-Control-Allow-Headers: Content-Type, Authorization
```

**方案二：使用代理**

编辑 `quasar.config.js`:
```javascript
devServer: {
  proxy: {
    '/api': {
      target: 'http://your-backend-url',
      changeOrigin: true
    }
  }
}
```

然后修改 `src/boot/axios.js`:
```javascript
const api = axios.create({ baseURL: '/api' })
```

## 生产环境构建

### 构建命令

```bash
npm run build
```

### 构建输出

构建文件位于：`dist/spa/`

### 部署建议

1. **静态文件服务器**
   - 将 `dist/spa/` 目录下的所有文件复制到Web服务器
   - 配置服务器将所有路由指向 `index.html`

2. **Nginx配置示例**

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/dist/spa;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API代理（如果需要）
    location /api/ {
        proxy_pass http://backend-server:3000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

3. **Apache配置示例**

```apache
<VirtualHost *:80>
    ServerName your-domain.com
    DocumentRoot /path/to/dist/spa
    
    <Directory /path/to/dist/spa>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
        
        # 启用重写引擎
        RewriteEngine On
        RewriteBase /
        RewriteRule ^index\.html$ - [L]
        RewriteCond %{REQUEST_FILENAME} !-f
        RewriteCond %{REQUEST_FILENAME} !-d
        RewriteRule . /index.html [L]
    </Directory>
</VirtualHost>
```

## 性能优化建议

1. **代码分割**
   - Quasar已自动配置路由级别的代码分割

2. **压缩**
   - 生产构建会自动压缩和优化代码

3. **缓存策略**
   - 配置Web服务器对静态资源启用缓存
   - 建议缓存时间：CSS/JS文件 1年，HTML文件不缓存

4. **CDN**
   - 将静态资源部署到CDN以提高加载速度
