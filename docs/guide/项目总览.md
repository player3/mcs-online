# MCS Online - 项目总览

## 📋 项目简介

MCS Online（门票自助打印系统）是一个基于 Vue 3 + Quasar Framework 开发的现代化Web应用，专为会议、展览等活动提供高效的门票验证和胸牌打印解决方案。

## 🎯 核心功能

### 1. 用户自助打印 👤
- **自定义九宫格键盘**: 大按钮设计，触摸友好
- **智能输入**: 自动添加分隔符，格式验证
- **实时验证**: 后台验证门票有效性
- **信息展示**: 验证通过后显示完整用户信息
- **一键打印**: 确认无误后即可打印胸牌

### 2. 管理员查询 🔍
- **多条件搜索**: 支持姓名、手机、邮箱、门票号查询
- **结果列表**: 清晰展示所有匹配记录
- **详细信息**: 查看用户完整资料
- **打印管理**: 手动触发打印，查看打印状态
- **记录追踪**: 显示打印时间和状态

## 🚀 快速开始

### 三步启动

1. **安装依赖**
   ```bash
   npm install
   npm install express cors body-parser
   ```

2. **启动Mock服务器**（新终端）
   ```bash
   node mock-server.js
   ```

3. **启动前端应用**
   ```bash
   npm run dev
   ```

访问：`http://localhost:9000`

## 📡 API接口

### 1. 查询门票
```
GET /api/tickets/:ticketNumber
```

### 2. 搜索用户
```
GET /api/users/search?name=xxx&phone=xxx&email=xxx&ticketNumber=xxx
```

### 3. 打印胸牌
```
POST /api/print
Body: { ticketNumber, userInfo }
```

详细API文档请查看 `README.md`

## 🔨 开发指南

### 添加新功能

1. **新页面**: `src/pages/` 目录添加组件
2. **新路由**: `src/router/routes.js` 配置路由
3. **新API**: `src/services/api.js` 添加接口
4. **新样式**: `src/css/app.scss` 添加样式

### 代码规范

```bash
# 检查代码
npm run lint

# 格式化代码
npm run format
```

### 构建生产版本

```bash
npm run build
```

输出目录：`dist/spa/`

## 📦 部署

### 前端部署
- 构建后将 `dist/spa/` 目录部署到Web服务器
- 配置服务器将所有路由指向 `index.html`

### 后端要求
- 实现对应的API接口
- 配置CORS允许跨域请求
- 确保API返回格式符合约定

详细部署指南请查看 `环境配置说明.md`
