  一、快速启动（推荐）
═══════════════════════════════════════════════════════════════

Windows用户：
    双击运行：start-dev.bat

Linux/macOS用户：
    执行命令：chmod +x start-dev.sh && ./start-dev.sh

═══════════════════════════════════════════════════════════════
  二、手动启动（真实环境）
═══════════════════════════════════════════════════════════════

1. 安装依赖（首次运行）：
   yarn install

2. 启动测试打印服务（终端1）：
   node test-print-server.js
   
   打印服务地址：http://localhost:6789
   测试页面：http://localhost:6789/test

3. 启动前端应用（终端2）：
   yarn dev

4. 浏览器访问：
   http://localhost:9000
   
═══════════════════════════════════════════════════════════════
  三、Mock模式启动（测试用）
═══════════════════════════════════════════════════════════════

1. 启动Mock服务器（终端1）：
   node mock-server.js

2. 启动前端应用（终端2）：
   yarn dev

═══════════════════════════════════════════════════════════════
  四、功能说明
═══════════════════════════════════════════════════════════════

【自助签到打印页面】
  1. 使用九宫格键盘输入门票编号
  2. 格式：dddd-dddd-dddd（自动添加横线）
  3. 点击"确认签到"进行签到验证
  4. 查看用户信息并打印胸牌
  5. 打印数据发送到本地打印服务（localhost:6789）

【管理查询页面】
  1. 输入查询条件（姓名/手机/邮箱/门票）
  2. 点击"查询"搜索用户或按回车键触发查询
  3. 选择用户查看详细信息
  4. 点击"打印胸牌"进行打印
  
  ⭐新功能 - 门票编号自动查询：
  - 输入完整门票编号（dddd-dddd-dddd）后自动查询
  - 查询完成后文本框内容自动全选
  - 可直接输入下一个门票编号，无需手动清空
  - 适合批量签到和快速打印场景
  
  ⭐新功能 - 回车键快速查询：
  - 在任意输入框按回车键即可触发查询
  - 减少鼠标操作，提升查询效率
  - 支持纯键盘操作，更加流畅便捷

【打印服务】
  - 本地打印服务地址：http://localhost:6789
  - 打印接口：POST /postname
  - 测试页面：http://localhost:6789/test
  - 启动命令：node test-print-server.js
  - 详细说明：查看《打印服务说明.md》

  五、常见问题
═══════════════════════════════════════════════════════════════

问：端口被占用怎么办？
答：修改配置文件中的端口：
    - 前端：quasar.config.js -> devServer.port
    - 后端：mock-server.js -> PORT

问：依赖安装失败？
答：尝试清除缓存：
    npm cache clean --force
    删除 node_modules 文件夹
    重新运行 npm install

问：页面无法连接API？
答：确认Mock服务器是否正在运行
    访问 http://localhost:3000/api/health 测试

问：想连接真实后台？
答：修改 src/boot/axios.js 中的 baseURL
