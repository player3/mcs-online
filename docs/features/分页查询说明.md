# 分页查询功能说明

## 📝 概述

管理员查询页面使用 `AutoSearch` 接口进行分页查询，支持按姓名、门票编号、邮箱、手机号等条件搜索用户。

## 🔧 接口说明

### 接口地址
```
GET /api/v2/AutoSearch
```

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| sessionId | string | 是 | 会话ID |
| page | int | 是 | 页码（**从0开始**，0表示第一页） |
| pageSize | int | 是 | 每页条数 |
| name | string | 否 | 姓名 |
| regcode | string | 否 | 门票编号 |
| email | string | 否 | 邮箱 |
| mobile | string | 否 | 手机号 |

### 请求示例

```javascript
// 第一页（page=0）
GET /api/v2/AutoSearch?sessionId=xxx&page=0&pageSize=10&name=张三&mobile=13800138000

// 第二页（page=1）
GET /api/v2/AutoSearch?sessionId=xxx&page=1&pageSize=10&name=张三&mobile=13800138000
```

**重要提示：** page参数从0开始，0表示第一页，1表示第二页，以此类推。

### 响应格式

```json
{
  "success": true,
  "code": 200,
  "data": [
    {
      "id": "1",
      "name": "张三",
      "mobile": "13800138000",
      "email": "zhangsan@example.com",
      "regcode": "1234-5678-9012",
      "type": "VIP",
      "company": "某某公司",
      "position": "经理"
    },
    // ... 更多用户数据
  ],
  "total": 100  // 总记录数
}
```

## 💻 前端实现

### 1. 分页数据结构

```javascript
const pagination = ref({
  page: 1,        // 当前页码
  pageSize: 10,   // 每页条数
  total: 0        // 总记录数
})
```

### 2. 查询函数

```javascript
const searchUser = async (page = 1) => {
  // 更新当前页码（UI显示从1开始）
  pagination.value.page = page

  // 转换为API页码（从0开始）
  const apiPage = page - 1  // UI的第1页对应API的第0页

  // 调用 AutoSearch 接口
  const response = await api.get('/AutoSearch', {
    params: {
      sessionId: sessionId.value,
      page: apiPage,  // 传递从0开始的页码
      pageSize: pagination.value.pageSize,
      name: queryForm.value.name || '',
      regcode: queryForm.value.ticketNumber || '',
      email: queryForm.value.email || '',
      mobile: queryForm.value.phone || ''
    }
  })

  if (response.data && response.data.success) {
    searchResults.value = response.data.data || []
    pagination.value.total = response.data.total || 0
  }
}
```

**页码转换说明：**
- **UI显示**：从1开始（第1页、第2页...）
- **API传递**：从0开始（page=0、page=1...）
- **转换公式**：`apiPage = uiPage - 1`

### 3. 分页组件

```html
<q-pagination
  v-model="pagination.page"
  :max="Math.ceil(pagination.total / pagination.pageSize)"
  :max-pages="7"
  direction-links
  boundary-links
  @update:model-value="onPageChange"
  color="primary"
/>
```

## 🎯 功能特性

### 1. 多条件查询
- ✅ 支持姓名、手机号、邮箱、门票编号搜索
- ✅ 至少需要一个查询条件
- ✅ 支持模糊匹配

### 2. 分页显示
- ✅ 每页显示10条记录（可配置）
- ✅ 显示总记录数和当前页数
- ✅ 支持首页、上一页、下一页、尾页跳转
- ✅ 显示页码范围（最多7页）

### 3. 用户体验
- ✅ 加载提示动画
- ✅ 查询成功提示
- ✅ 错误信息提示
- ✅ 控制台日志便于调试

### 4. 数据展示
- ✅ 列表显示查询结果
- ✅ 点击用户查看详细信息
- ✅ 支持打印胸牌

## ⚙️ 配置说明

编辑 `src/pages/AdminQueryPage.vue`:

```javascript
const pagination = ref({
  page: 1,
  pageSize: 20,  // 改为20条每页
  total: 0
})
```

### SessionId 获取

当前 sessionId 为空字符串，可以从以下方式获取：

1. **从登录信息获取**
```javascript
const sessionId = ref(localStorage.getItem('sessionId') || '')
```

2. **从路由参数获取**
```javascript
const sessionId = ref(route.query.sessionId || '')
```

3. **从Store获取**
```javascript
const sessionId = computed(() => userStore.sessionId)
```

## ❗ 注意事项

1. **至少一个查询条件**
   - 必须填写姓名、手机、邮箱或门票编号之一
   - 否则显示警告提示

2. **SessionId 必须有效**
   - 需要确保 sessionId 正确
   - 无效的 sessionId 会导致查询失败

3. **分页从0开始（后端）**
   - API的 page 参数从 0 开始计数
   - page=0 表示第一页，page=1 表示第二页
   - 前端UI显示从1开始，但会自动转换为从0开始传给后端
   - 不要传入负数

4. **总页数计算**
   - 总页数 = Math.ceil(total / pageSize)
   - 向上取整确保显示所有数据
