# 打印功能重构说明

## 重构目标

将原本分散在 `SelfPrintPage.vue` 和 `AdminQueryPage.vue` 中的打印逻辑提取到公共工具函数中，实现代码复用和统一管理。

## 新增文件

### `src/utils/printUtils.js`

公共打印工具模块，提供以下功能：

#### 1. `printBadge(userInfo, fieldList, eventData)`

核心打印函数，负责：
- 准备打印数据（展开用户信息）
- 根据 `fieldList` 配置转换字段值
- 根据 `eventData` 添加中英文字段映射
- 调用本地打印服务（`http://localhost:6789/postname`）

**参数：**
- `userInfo` (Object): 用户信息对象
- `fieldList` (Array): 字段列表配置，用于值转换
- `eventData` (Object): 事件数据，用于字段映射

**返回：**
- Promise: 打印服务的响应

**使用示例：**
```javascript
import { printBadge } from 'src/utils/printUtils'

try {
  await printBadge(userInfo.value, fieldList.value, eventData.value)
  console.log('打印成功')
} catch (error) {
  console.error('打印失败:', error)
}
```

#### 2. `printBadgeBatch(userList, fieldList, eventData)`

批量打印函数，用于一次性打印多个用户的胸牌。

**参数：**
- `userList` (Array): 用户列表
- `fieldList` (Array): 字段列表配置
- `eventData` (Object): 事件数据

**返回：**
- Promise: 包含批量打印结果的对象
  ```javascript
  {
    total: 10,        // 总数
    success: 8,       // 成功数
    failed: 2,        // 失败数
    results: [...],   // 成功的结果
    errors: [...]     // 失败的错误
  }
  ```

**使用示例：**
```javascript
import { printBadgeBatch } from 'src/utils/printUtils'

const result = await printBadgeBatch(selectedUsers, fieldList.value, eventData.value)
console.log(`成功: ${result.success}/${result.total}`)
```

#### 3. `checkPrintServiceAvailable()`

检查本地打印服务是否可用。

**返回：**
- Promise<boolean>: 服务是否可用

**使用示例：**
```javascript
import { checkPrintServiceAvailable } from 'src/utils/printUtils'

const isAvailable = await checkPrintServiceAvailable()
if (!isAvailable) {
  console.warn('打印服务不可用')
}
```

## 修改的文件

### 1. `src/pages/SelfPrintPage.vue`

**变更：**
- 移除了 `axios` 的导入（改为使用 `printUtils`）
- 导入公共打印函数：`import { printBadge } from 'src/utils/printUtils'`
- 将原来的 `printBadge` 方法重命名为 `handlePrintBadge`
- 简化打印逻辑，直接调用公共函数：
  ```javascript
  await printBadge(userInfo.value, fieldList.value, eventData.value)
  ```

**代码行数减少：** 约 30 行（从 ~60 行减少到 ~25 行）

### 2. `src/pages/AdminQueryPage.vue`

**变更：**
- 移除了 `axios` 的导入（改为使用 `printUtils`）
- 导入公共打印函数：`import { printBadge } from 'src/utils/printUtils'`
- 简化 `handlePrint` 方法，使用公共函数
- 简化 `printUserBadge` 方法，使用公共函数

**修改的方法：**
1. `handlePrint(user)` - 表格中的打印操作
2. `printUserBadge()` - 选中用户的打印操作

**代码行数减少：** 约 60 行（两个方法共减少）

## 数据流程

```
用户操作
  ↓
页面组件 (SelfPrintPage / AdminQueryPage)
  ↓
调用 printBadge(userInfo, fieldList, eventData)
  ↓
printUtils.js
  ├─ 准备打印数据
  ├─ 转换字段值
  ├─ 添加字段映射
  └─ 调用打印服务
      ↓
http://localhost:6789/postname
  ↓
打印成功/失败
  ↓
页面更新状态
```

## 打印数据处理流程

### 1. 数据准备
```javascript
const printData = {
  ...userInfo,
  name: userInfo.name,
  regcode: userInfo.regcode || userInfo.ticketNumber
}
```

### 2. 字段值转换
根据 `fieldList` 配置，将数字索引转换为对应的标签：
```javascript
// 如果字段值为 "0"，根据配置转换为 "VIP"
// 如果字段值为 "1"，根据配置转换为 "普通"
```

### 3. 字段映射
根据 `eventData` 配置，添加中英文字段：
```javascript
// 原字段: ticketType: "VIP"
// 映射后: ticketType: "VIP", "票种 Type": "VIP"
```

### 4. 发送打印
将处理后的数据发送到本地打印服务。

## 使用注意事项

1. **确保打印服务运行**
   ```bash
   node test-print-server.js
   ```

2. **字段配置必须加载**
   - 页面需要在 `onMounted` 时调用 `getEventFields()`
   - 确保 `fieldList` 和 `eventData` 已正确加载

3. **错误处理**
   - 调用方需要处理 try-catch
   - 打印失败会抛出异常

4. **数据完整性**
   - 确保传入的 `userInfo` 包含必要字段（name, regcode）
   - `fieldList` 和 `eventData` 可以为空（但可能影响打印效果）
