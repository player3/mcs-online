# 打印配置管理说明

## 功能概述
新增设置页面，用于查看和管理打印配置。通过接口获取 XML 格式的打印配置，并以友好的界面展示配置详情。

## 功能特点
- ✅ 自动解析 XML 配置文件
- ✅ 可视化展示卡片配置（尺寸、打印图片选项）
- ✅ 展示二维码配置（DPI、尺寸、位置）
- ✅ 表格形式展示文本打印配置（支持分页、排序）
- ✅ 支持刷新配置功能
- ✅ Material Design 风格界面

## 访问方式

### 方式一：通过管理查询界面
1. 进入**管理查询界面**（AdminQueryPage）
2. 点击页面右上角的"打印配置"按钮
3. 跳转到配置管理页面

### 方式二：直接访问 URL
```
http://localhost:9000/#/settings
```

**注意**: 设置入口仅在管理查询界面显示，普通用户无法访问。

## 配置信息展示

### 1. 卡片配置
- **宽度**: 卡片宽度（单位：px）
- **高度**: 卡片高度（单位：px）
- **打印图片**: 是否打印背景图片

### 2. 二维码配置
- **DPI**: 二维码分辨率
- **尺寸**: 二维码宽度×高度（单位：px）
- **位置**: 二维码在卡片上的坐标 (X, Y)

### 3. 文本打印配置
每个文本配置项包含以下信息：

| 字段 | 说明 |
|------|------|
| 文本内容 | 要打印的文本或字段标识 |
| 尺寸 | 文本框宽度×高度 |
| 位置 | 文本框在卡片上的坐标 (X, Y) |
| 字体 | 字体类型和字号 |
| 对齐方式 | 横向和纵向对齐方式 |
| 属性 | 粗体、兼容模式、打印行数等 |

## API 接口

### 接口地址
```
GET http://localhost:6789/printConfig
```

**注意**: 直接调用本地打印服务，不通过后端 API 代理。

### 返回格式
返回 XML 格式的打印配置文件

### XML 配置结构
```xml
<CustomSetting>
  <Card>
    <Width>360</Width>
    <Height>480</Height>
    <PrintImage>false</PrintImage>
    
    <QRCode>
      <Dpi>150</Dpi>
      <Width>55</Width>
      <Height>55</Height>
      <X>153</X>
      <Y>326</Y>
    </QRCode>
    
    <PrintTexts>
      <PrintTextSetting>
        <Text>姓名 Name</Text>
        <Width>118</Width>
        <Height>24</Height>
        <X>199</X>
        <Y>244</Y>
        <FontType>黑体</FontType>
        <FontSize>18</FontSize>
        <Blod>false</Blod>
        <StringAlgin>Center</StringAlgin>
        <LineAlignment>Center</LineAlignment>
        <Arrange>X</Arrange>
        <bCompatible>false</bCompatible>
        <TextPrintRow>1</TextPrintRow>
        <LimitLen>0</LimitLen>
      </PrintTextSetting>
      <!-- 更多文本配置... -->
    </PrintTexts>
  </Card>
</CustomSetting>
```

## 使用场景

### 场景一：查看当前打印配置
1. 进入管理查询界面
2. 点击右上角"打印配置"按钮
3. 系统自动加载并展示当前配置
4. 查看卡片尺寸、二维码和文本配置详情

### 场景二：配置更新后刷新
1. 打印服务修改配置文件
2. 在设置页面点击"刷新配置"按钮
3. 系统重新从 `http://localhost:6789/printConfig` 获取并展示最新配置

### 场景三：故障排查
1. 打印出现问题时，从管理查询界面进入配置页面
2. 检查文本位置、字体、尺寸是否正确
3. 确认二维码配置是否合理
4. 验证打印服务是否正常运行

## 注意事项

### ⚠️ XML 字段拼写
原 XML 配置中存在拼写错误（保持兼容）：
- `Blod` → 应为 `Bold`（粗体）
- `StringAlgin` → 应为 `StringAlign`（对齐）

### ⚠️ 打印服务要求
- 打印服务必须运行在 `http://localhost:6789`
- 确保 `/printConfig` 接口返回正确的 XML 格式配置
- 接口超时时间设置为 5 秒

### ⚠️ 访问权限
- 设置入口仅在**管理查询界面**显示
- 普通用户（自助打印页面）无法访问配置页面
