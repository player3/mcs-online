# 打印服务说明

## 📝 概述

本系统使用本地打印服务进行胸牌打印，打印服务监听在 `http://localhost:6789`。

## 🔧 打印接口

### 接口地址
```
POST http://localhost:6789/postname
```

### 请求头
```
Content-Type: application/json
```

### 请求体格式

系统会将用户的完整信息发送到打印服务：

```json
{
  "name": "xu",
  "regcode": "1234-5678-9012",
  "mobile": "13800138000",
  "email": "example@email.com",
  "ticketType": "VIP",
  "姓名 Name": "xuminghui",
  // ... 其他从后台获取的用户字段
}
```

### 响应格式

打印服务可以返回任意格式，系统会处理：

```json
{
  "success": true,
  "message": "打印成功"
}
```

## 🚀 使用流程

1. **用户签到**
   - 输入门票编号（格式：dddd-dddd-dddd）
   - 点击"确认签到"按钮
   - 系统调用 `GET /api/v2/AutoSignin?regcode=xxxx` 获取用户信息

2. **显示用户信息**
   - 弹出对话框显示用户详细信息
   - 包括：姓名、手机号、邮箱、门票编号、类型等

3. **打印胸牌**
   - 点击"打印胸牌"按钮
   - 系统将用户完整信息发送到本地打印服务
   - 打印服务地址：`http://localhost:6789/postname`

## 📡 数据流转

```
用户输入门票号
    ↓
调用签到接口（https://iccad2025.mymova.com/api/v2/AutoSignin）
    ↓
获取用户完整信息
    ↓
显示用户信息对话框
    ↓
点击打印按钮
    ↓
发送用户信息到本地打印服务（http://localhost:6789/postname）
    ↓
打印完成
```

## 🔍 数据字段说明

### 主要字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| name | 英文名/用户名 | "xu" |
| regcode | 门票编号 | "1234-5678-9012" |
| mobile | 手机号 | "13800138000" |
| email | 邮箱 | "example@email.com" |
| ticketType | 票类型 | "VIP" |
| 姓名 Name | 中文姓名 | "徐明辉" |

### 其他字段

打印服务会收到从后台返回的**所有用户字段**，包括：
- 用户基本信息
- 自定义字段（通过 GetEventFields 配置）
- 活动相关字段

## 💻 代码实现

### 打印函数（SelfPrintPage.vue）

```javascript
const printBadge = async () => {
  $q.loading.show({
    message: '正在打印胸牌...'
  })

  try {
    // 准备打印数据，包含用户的所有信息
    const printData = {
      ...userInfo.value, // 展开所有用户信息
      name: userInfo.value.name,
      regcode: userInfo.value.regcode
    }

    console.log('发送打印数据:', printData)

    // 调用本地打印服务
    const response = await axios.post('http://localhost:6789/postname', printData, {
      headers: {
        'Content-Type': 'application/json'
      }
    })

    console.log('打印响应:', response.data)

    // 打印成功
    $q.notify({
      type: 'positive',
      message: '胸牌打印成功！'
    })
    showUserInfo.value = false
    clearInput()
  } catch (error) {
    console.error('打印失败:', error)
    const errorMsg = error.response?.data?.message || error.message || '打印失败，请联系管理员'
    $q.notify({
      type: 'negative',
      message: errorMsg
    })
  } finally {
    $q.loading.hide()
  }
}
```

## 🛠️ 打印服务要求

### 必需条件
1. 打印服务必须运行在 `http://localhost:6789`
2. 监听路径：`/postname`
3. 支持 POST 请求
4. 接受 JSON 格式数据

### 推荐实现
- 支持 CORS（如果需要）
- 返回明确的成功/失败状态
- 提供详细的错误信息

### 常见问题

**1. 连接被拒绝（Connection Refused）**
- 确认打印服务是否正在运行
- 检查端口 6789 是否正确
- 确认没有防火墙阻止

**2. CORS 错误**
- 打印服务需要设置 CORS 头
- 允许来自前端应用的请求

**3. 超时错误**
- 检查打印服务响应时间
- 确认网络连接正常

## 📝 示例打印服务

### Node.js 示例

```javascript
const express = require('express')
const cors = require('cors')
const app = express()

app.use(cors())
app.use(express.json())

app.post('/postname', (req, res) => {
  console.log('收到打印请求:', req.body)
  
  // 这里实现实际的打印逻辑
  // 例如：生成PDF、发送到打印机等
  
  // 返回成功响应
  res.json({
    success: true,
    message: '打印成功'
  })
})

app.listen(6789, () => {
  console.log('打印服务运行在 http://localhost:6789')
})
```

### Python 示例

```python
from flask import Flask, request, jsonify
from flask_cors import CORS

app = Flask(__name__)
CORS(app)

@app.route('/postname', methods=['POST'])
def print_badge():
    data = request.get_json()
    print('收到打印请求:', data)
    
    # 这里实现实际的打印逻辑
    
    return jsonify({
        'success': True,
        'message': '打印成功'
    })

if __name__ == '__main__':
    app.run(port=6789)
```
