## 🚀 快速使用

### 导入打印工具
```javascript
import { printBadge } from 'src/utils/printUtils'
```

### 单个打印
```javascript
try {
  await printBadge(userInfo, fieldList, eventData)
  console.log('打印成功')
} catch (error) {
  console.error('打印失败:', error)
}
```

### 批量打印
```javascript
import { printBadgeBatch } from 'src/utils/printUtils'

const result = await printBadgeBatch(userList, fieldList, eventData)
console.log(`成功: ${result.success}/${result.total}`)
```

### 检查打印服务
```javascript
import { checkPrintServiceAvailable } from 'src/utils/printUtils'

const isAvailable = await checkPrintServiceAvailable()
if (!isAvailable) {
  console.warn('打印服务不可用')
}
```

## 🔧 开发建议

### 添加新的打印功能
在 `src/utils/printUtils.js` 中添加新函数，然后在需要的页面导入使用。

### 修改打印逻辑
只需修改 `src/utils/printUtils.js` 中的 `printBadge` 函数，所有使用该函数的页面会自动更新。

### 测试打印功能
1. 启动打印服务：`node test-print-server.js`
2. 运行测试示例（如果需要）

## ⚠️ 注意事项

1. 确保打印服务运行在 `http://localhost:6789`
2. 页面需要先调用 `getEventFields()` 加载配置
3. 传入的用户信息必须包含 `name` 和 `regcode`（或 `ticketNumber`）
