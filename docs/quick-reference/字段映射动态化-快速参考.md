# 字段映射动态化 - 快速参考

## 📋 改动说明

用户详情弹窗的字段名称现在使用后端配置的动态映射，不再是硬编码。

## ✨ 主要优势

| 特性 | 说明 |
|------|------|
| 🌐 **中英文双语** | 显示如 "姓名 Name"、"手机 Cell Phone" |
| 🔧 **自定义字段** | 支持 `cf_*` 开头的自定义字段 |
| 📝 **后端配置** | 字段名称由后端管理，前端无需修改 |
| 🔄 **自动更新** | 后端修改配置后自动生效 |

## 🎯 映射逻辑（四层后备机制）

```
字段 key
    ↓
第一层：查找 eventData
    ↓
找到了吗？
├─ 是 → 返回 eventData[key]（中英文双语）
│
└─ 否 ↓
第二层：查找 fieldList
    ↓
找到了吗？
├─ 是 → 返回 field.describe（字段描述）
│
└─ 否 ↓
第三层：查找默认映射
    ↓
找到了吗？
├─ 是 → 返回默认值
│
└─ 否 ↓
第四层：返回原始 key
```

## 💻 代码示例

### 修改后的代码（四层后备）

```javascript
const formatFieldName = (key) => {
  // 第一层：优先使用 eventData 中的映射
  if (eventData.value && eventData.value[key]) {
    return eventData.value[key]
  }
  
  // 第二层：从 fieldList 中查找字段描述
  if (fieldList.value && fieldList.value.length > 0) {
    const field = fieldList.value.find(f => f.name === key)
    if (field && field.describe) {
      return field.describe
    }
  }
  
  // 第三层：使用默认映射
  const defaultFieldNameMap = {
    regcode: '门票编号',
    ticketNumber: '门票编号',
    type: '类型',
    ticketType: '票种',
    printed: '打印状态',
    signed: '签到状态',
    // ...
  }
  
  // 第四层：返回原始 key
  return defaultFieldNameMap[key] || key
}
```

## ✅ 兼容性

### 四层后备机制

1. **第一层**: eventData 映射（最优先，中英文双语）
2. **第二层**: fieldList 描述（字段描述信息）
3. **第三层**: 默认映射（兼容旧字段）
4. **第四层**: 原始 key（保证显示）

### 示例

```javascript
// 场景1: eventData 中有映射
formatFieldName('name')  // → "姓名 Name"

// 场景2: eventData 没有，但 fieldList 有
formatFieldName('customField')  // → fieldList 中的 describe 值

// 场景3: 前两者都没有，但默认映射有
formatFieldName('printed')  // → "打印状态"

// 场景4: 都没有，显示原始值
formatFieldName('newField')  // → "newField"
```

## ⚠️ 注意事项

1. **确保 API 调用**
   - `getEventFields()` 必须在页面加载时调用
   - 检查 eventData 是否正确加载

2. **字段 key 一致性**
   - 后端返回的 key 要与 eventData 中的 key 匹配
   - 大小写敏感

3. **默认映射更新**
   - 保留常用字段的默认映射
   - 作为 eventData 加载失败的后备
